# Bookstore Management System

A C-based bookstore management system developed to practice structured programming, file handling, searching, insertion, deletion, and persistent data storage.

## Features

- Add new books
- Search for books using their BIN
- Remove books from the system
- Maintain book records in sorted order
- Store and load book data using text files
- Manage book names, BIN values, and prices
- Preserve data between program executions

## Technologies

- C
- File I/O
- Arrays and structures
- Searching and sorting
- Modular programming

## Project Structure

The project is organized around a set of functions responsible for managing bookstore records and handling persistent storage through external files.

Typical operations include:

- Loading book data from file
- Adding new records
- Searching existing records
- Removing records
- Saving updated data
